# LexiCon (`nsvector-lexicon`)

**Catch words while you read. Drill them until they stick.**

NorthStar Vector Focus product — personal word bank with flip cards and 4-option quizzes. Local-first. No streaks, no leaderboards, no dependency on Word Cards AI or OneRead code.

Planned URL: `https://lex.nsvector.com` (DNS later).

## Local run

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://127.0.0.1:5173`).

## Scripts

| Command        | Purpose              |
|----------------|----------------------|
| `npm run dev`  | Vite dev server      |
| `npm run build`| Typecheck + production build |
| `npm run preview` | Preview production build |
| `npm run test` | Vitest               |
